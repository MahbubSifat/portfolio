# Md. Mahbubul Alom Sifat — Animated Portfolio

A modern, animated portfolio website showcasing my technical skills, selected projects, and journey as a Software Engineering student at the University of Frontier Technology, Bangladesh (UFTB).

Built with React and Vite, this portfolio features a dark visual theme, smooth scrolling, interactive animations, and a responsive layout.

## ✨ Features

- Animated hero and about sections
- Responsive design for desktop, tablet, and mobile
- Technical skills organized by category
- Selected projects with GitHub repositories and live demos
- Contact section with email and social links
- Smooth scrolling and interactive UI animations
- Modern dark theme with cyan accents

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript, HTML5, CSS3
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Animations:** GSAP, Motion, Lenis
- **Icons:** Lucide React
- **Deployment:** Vercel

## 🚀 Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)

### Installation

Clone the repository:

```bash
git clone https://github.com/MahbubSifat/animated-portfolio.git
```

Navigate to the project directory:

```bash
cd animated-portfolio
```

Install dependencies:

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

### Build for Production

```bash
npm run build
```

### Preview the Production Build

```bash
npm run preview
```
